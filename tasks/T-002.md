# T-002 · Supabase schema, RLS, append-only triggers, cron

Day: 0 · Layer: L0 · Estimate: 3h · Depends on: T-001 · PRD: PRD §9, FR-1.1, FR-10.1

## Goal
The full data model as numbered migrations, RLS so anon reads only public rows, triggers that reject update/delete on append-only tables, and a pg_cron job hitting /api/cron/tick every 15 min with a secret.

## In scope
- migrations 001_schema.sql, 002_rls.sql, 003_append_only.sql, 004_cron.sql
- seed.sql with one agent 'book-daily' in dry_run
- env.ts with Zod for all vars in ARCH §6
- docs/runbook.md: how to apply migrations

## Out of scope
- Any application logic
- Real cron secret in repo

## Acceptance criteria
1. `supabase db push` applies cleanly on an empty project
2. UPDATE on treasury_snapshots/usage_events/decisions/book_snapshots fails with a trigger error (test)
3. anon SELECT on decisions returns only public=true rows (test)
4. cron.job row exists with schedule '*/15 * * * *'
5. App refuses to boot on a missing required env var and names it
