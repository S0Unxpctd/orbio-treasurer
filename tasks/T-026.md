# T-026 · Registry: push endpoint + agent tokens + first-boot registration

Day: 5 · Layer: L0 · Estimate: 3h · Depends on: T-025, T-018 · PRD: FR-7.2, FR-8.2

## Goal
External agents register and push public metrics signed with an agent token; replay-protected; aggregator stores only public data.

## In scope
- POST /api/registry (register, returns nothing secret; token generated client-side and hashed server-side)
- POST /api/registry/:slug/push with HMAC + as_of monotonic check
- Kit: register on first boot, push after each tick, opt-out flag

## Out of scope
- Any control channel from aggregator to agents

## Acceptance criteria
1. Replayed push rejected
2. Payload schema == FR-6.1 shape + decisions; anything else rejected
3. A kit-generated agent appears on the aggregator within one tick (evidence)

## Audit focus
- Tokens stored in clear
- Payload accepting secrets by accident

## Tests required
- integration: registry.test.ts; e2e with T-025 output
