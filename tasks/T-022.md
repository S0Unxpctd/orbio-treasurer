# T-022 · X client + numbers validator

Day: 4 · Layer: L1 · Estimate: 2.5h · Depends on: T-017 · PRD: FR-9.1, PRD §11

## Goal
Post to X API v2 with OAuth 1.0a, plus a validator that every number in generated copy equals a ledger value.

## In scope
- x/client.ts (post, dry-run flag)
- validator: extract numbers, match to a provided facts map with tolerance for rounding
- POST_BLOCKED decision on mismatch

## Out of scope
- Scheduling (T-023)

## Acceptance criteria
1. Validator blocks a post with a wrong number and passes an exact one (tests)
2. Dry-run prints the post without sending
3. Free-tier limit confirmed and recorded in api-notes

## Audit focus
- Tokens in logs
- Number extraction misses % or $ formats

## Tests required
- unit: validator.test.ts; manual: one real post to a test account
