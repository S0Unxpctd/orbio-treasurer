## Goal
One idempotent tick that reads MCP balance + key status + book, computes metrics, writes a treasury_snapshot and a book_snapshot. Wired to POST /api/cron/tick with the secret.

## In scope
- core/tick.ts keyed by (agent_id, 15-min bucket)
- apps/web/app/api/cron/tick/route.ts with x-cron-secret check
- reconciliation_delta computed
- TICK_FAILED decision on error

2. Wrong secret → 401, no side effects
3. Snapshots appear every 15 min for the seeded agent for ≥ 3 hours (evidence: query output)
