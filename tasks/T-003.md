# T-003 · redact() + structured logger

Day: 0 · Layer: L0 · Estimate: 1.5h · Depends on: T-001 · PRD: PRD §11, FR-2.1

## Goal
A single log() function producing JSON lines, with a mandatory redact() that masks anything looking like a key/token to prefix…last4.

## In scope
- redact.ts with patterns for sk-or-*, Bearer tokens, 32+ char hex/base64 blobs, env var names ending _KEY/_SECRET/_TOKEN
- log.ts with levels and a context object
- ESLint-style Biome rule or unit test asserting no console.log in packages/core

## Out of scope
- Third-party logging SDKs

## Acceptance criteria
1. redact('sk-or-v1-TESTONLYabcdef1234') === 'sk-or-…1234'
2. Nested objects and error stacks are redacted
3. log() output parses as JSON and never contains a fixture secret (test greps)

## Audit focus
- Regex that misses keys embedded in URLs or error messages

## Tests required
- unit: redact.test.ts (table-driven, ≥ 15 cases)
