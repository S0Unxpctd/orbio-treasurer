## Build notes
Built `packages/core/src/redact.ts` and `packages/core/src/log.ts`, both pure TS, no I/O beyond
`console.error`/`process.env`, no new dependencies.

- `redact(value)` deep-walks strings, arrays, plain objects and `Error` (message + stack, plus
  any extra own-enumerable props) and masks secret-shaped substrings via a sequential
  regex-replace pipeline (most specific pattern first, so an already-masked span — which
  contains `…` — can never be re-matched by a later, more generic pattern):
  1. `Bearer <token>` — keeps the scheme word, masks only the token (recursing into the same
     shape-detection used for a bare string).
  2. `sk-or-...` (Orbio/OpenRouter) → `sk-or-…<last4>`.
  3. generic `sk-...` → `sk-…<last4>`.
  4. `0x`+64-hex private key → `0x…<last4>` (fully masked; deliberately does NOT match
     `0x`+40-hex addresses, which stay public).
  5. JWT-looking `xxx.yyy.zzz` → `<first4>…<last4>`.
  6. opaque blob, `[A-Za-z0-9_-]{32,}` → `<first4>…<last4>`, EXCEPT when the candidate is a
     UUID, an `0x`+40-hex address, or purely digits — those are explicitly exempted so they
     survive unmasked.
  - Because this is a plain string scan (not URL- or stack-trace-aware), it finds secrets
    embedded in query strings, basic-auth userinfo, and Error messages/stacks for free — no
    special-cased URL parsing needed (see Audit focus below).
  - Any object key ending in `_KEY`/`_SECRET`/`_TOKEN`/`_PK`/`_PASSWORD` (case-insensitive)
    masks its *whole* value regardless of shape — a string gets the same masking as above (or
    a `<redacted>` placeholder if it doesn't match a known pattern and is short), a non-string
    (object/array/number/bool) becomes the literal `'[REDACTED]'`.
  - `REDACTION_PATTERNS` is exported (7 named regexes) for direct pattern-level testing.
- `log(level, msg, ctx?)` prints exactly one `JSON.stringify`'d line via `console.error`
  (Biome's `noConsole` rule allows only `"error"` in `packages/core`, confirmed in `biome.json`)
  with `{ ts: new Date().toISOString(), level, msg, ...redact(ctx) }`. `LOG_LEVEL` env var sets
  the threshold (`debug|info|warn|error`, default `info`); an unrecognized value falls back to
  `info` rather than throwing. `createLogger(baseCtx)` returns `{debug,info,warn,error}` methods
  that merge `baseCtx` under the per-call `ctx` (call-site wins on key conflict).
- Did not export `redact`/`log` from `packages/core/src/index.ts` — the ticket's "In scope"
  names only `redact.ts`/`log.ts`; leaving `index.ts` untouched avoids any file overlap with the
  concurrent T-002 builder. A follow-up ticket can wire the barrel export when core's public API
  is assembled.
