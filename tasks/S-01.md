# S-01 · Gateway + router (`/v1/chat/completions`, `model: "auto"`)
Sprint 1.0 · Layer: L0 · Depends on: — · PRD: docs/PRD-1.0-sprint.md §3, §4 T-1, §6

## Goal
Any OpenAI-compatible client that changes only `base_url` and sends `model: "auto"` gets a completion served by the cheapest Orbio model that fits, with the real cost and the baseline cost captured per call.

## In scope
- `apps/web/app/v1/chat/completions/route.ts` (POST) and `apps/web/app/v1/models/route.ts` (GET). Node runtime, not edge.
- Caller auth: `Authorization: Bearer otk_<32 hex>`. For this ticket the valid keys come from env `GATEWAY_KEYS` (comma-separated `otk_…` values, hashed with sha256 at boot and compared by hash). A `CallerKeyStore` interface (`lookup(hash) → {keyId, agentId|null} | null`) is defined in `packages/core/src/router/keys.ts` with the env implementation; the DB implementation lands in S-02/S-06. Missing/unknown key → 401 JSON `{error:{type:"auth", message}}`.
- Router: `packages/core/src/router/` — pure `route(input, catalog, opts) → {model, tier, reason}` with NO I/O. Inputs: the request body (messages, tools, response_format, requested model), the model catalog (from `/models`, cached ≤10 min by the route handler), floor from `auto:S|M|L`, and `mode` (`normal|eco|critical`, default `normal`) from an env `TREASURER_MODE` for now.
  - Tiers from per-token input price in the catalog: S ≤ $0.40/M, M ≤ $3/M, L above. Defaults per tier = cheapest model in the tier among an allow-list env `ROUTER_ALLOW` (comma-separated ids; if unset, all).
  - Rules in order: `tools` present or `response_format` json → ≥ M; total prompt chars > 24 000 → ≥ M; system prompt matches /\b(reason|analy|code|plan)/i → ≥ M; else S. Then apply floor (`auto:X`), then policy cap (`eco` caps at M, `critical` caps at S; cap wins over floor and the reason says so).
  - Exact Orbio model id in `model` → pass through untouched (`tier` derived, `reason: "explicit"`).
  - Baseline model for savings: header `x-baseline-model` if present in the catalog, else tier-L default. `baselineCostUsd = tokens × baseline prices`.
- Upstream: forward to `${ORBIO_GATEWAY_BASE_URL}/chat/completions` with the Orbio key from env `ORBIO_KEY` (wallet-signed key derivation lands in S-03; keep a `getUpstreamKey()` seam). Streaming (`stream:true`) passes SSE through unchanged and reads the final `usage` chunk; non-stream reads `usage.cost` and `usage.*_tokens`. Response headers added: `x-treasurer-model`, `x-treasurer-tier`, `x-treasurer-reason`, `x-treasurer-cost-usd`, `x-treasurer-baseline-usd`.
- Every call → `recorder.record(CallRecord)` where `CallRecorder` is an interface in `packages/core/src/router/recorder.ts` with an in-memory implementation and a JSONL-to-stdout implementation (redacted). Fire-and-forget, one retry, never blocks the response. The ledger-backed recorder is S-02/S-06.
- Upstream 402/insufficient balance → 503 `{error:{type:"treasury_empty"}}`; upstream 5xx → 502 with the upstream status in the body; upstream body parsed with Zod (unknown extra fields tolerated; missing `usage` on non-stream → `AdapterShapeError`, response still returned to the caller, record marked `status:"no_usage"`).
- `GET /v1/models` proxies the Orbio catalog and adds `auto`, `auto:S`, `auto:M`, `auto:L` entries.
- Env additions in `packages/core/src/env.ts`: `GATEWAY_KEYS`, `ROUTER_ALLOW`, `TREASURER_MODE`. Update `docs/runbook.md` with a curl example.

## Out of scope
- Ledger writes, DB keys (S-02, S-06). Wallet-signed key (S-03). Policy/tick (S-06). Public page (S-08). Rate limiting. Caller billing.

## Acceptance criteria
1. `route()` is pure (no imports of fs/net/Date) and has table-driven tests covering: S/M/L classification from prices, each rule, floor, cap-over-floor, explicit model pass-through, unknown explicit model → error, baseline selection. ≥ 12 cases.
2. `POST /v1/chat/completions` without a key → 401; with a valid key and `model:"auto"` and a 5-word prompt → routed to tier S (asserted via `x-treasurer-tier`), response body is a valid OpenAI chat completion.
3. Same with `stream:true` → SSE chunks pass through and the recorder still receives a record with `costUsd` when the upstream sends a usage chunk.
4. `x-treasurer-cost-usd` equals upstream `usage.cost` (string, 6 decimals) and `x-treasurer-baseline-usd` = tokens × baseline prices from the catalog (test with a fake catalog).
5. `GET /v1/models` lists Orbio models plus the four `auto*` ids.
6. No secret in any log line or response (grep the diff; `redact()` on upstream error bodies).
7. Live check (only if `ORBIO_KEY` has balance; otherwise mark "not run: balance 0" in Evidence): one real call through the local server, `cost_usd > 0` in the recorder output.

## Audit focus
Key material in logs/headers; SSE passthrough not buffering the whole stream; `usage` parsing on stream end; 402 mapping; cap-over-floor; catalog cache staleness; Zod on upstream shapes.
